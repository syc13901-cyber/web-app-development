# 盒子模型（第四次实验）

《Web应用开发》课程第四次实验：围绕 **CSS 盒子模型** 完成 8 个渐进式练习页面，
全部使用原生 HTML + CSS，单个文件自包含（样式写在 `<style>` 中），无任何依赖。

## 实验内容

8 个页面由浅入深，逐步组合以下知识点：

| 文件 | 练习要点 |
|---|---|
| `1.html` | 嵌套盒子与行内并排（flex 混排）：外层红框容器 + 双列盒子 + 文本块 |
| `2.html` | 单侧 `border-left` / `padding-left` 的差异化盒子 |
| `3.html` | 固定宽度盒子（80px）的 `margin-right` 间隔排列 |
| `4.html` | 多盒子 + 文本内容的整体容器布局 |
| `5.html` | 与 4 同构的变式练习，调整间距与留白 |
| `6.html` | 百分比宽度（50%）+ 左右分栏（`left-wrap`）的复合布局 |
| `7.html` | 小尺寸（60px）多盒子排布与 `margin-top` 垂直间距 |
| `8.html` | 综合练习：容器 + 三盒子 + 文本块的收尾组合 |

## 覆盖的知识点

- 盒模型的四个层次：`content` → `padding` → `border` → `margin`
- `box-sizing: border-box` 与手动计算宽度的差异
- 四边独立控制：`margin-top / margin-right`、`padding-left`、`border-left` 等
- 用虚线边框可视化盒子边界，辅助理解嵌套关系

## 运行方式

直接用浏览器打开任意 `*.html` 文件即可，无需服务器、无需联网。
