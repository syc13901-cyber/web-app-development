# 个人主页（第五次实验）

《Web应用开发》课程第五次实验：制作一个**仿四川大学官网风格**的个人主页，
包含关于我、学习经历、通知公告、作品展示、学习资源与联系方式等板块。

## 实验约束

本次作业**只允许使用 DIV + CSS 传统布局技术**（float / inline-block / position /
margin auto），禁止使用 flex、grid 等课程未介绍的技术，页面样式全部手写在 `css/style.css` 中。

## 文件结构

```
05-个人主页/
├─ index.html        单页主体：顶栏 + 校徽区 + 导航 + 内容板块 + 页脚
├─ css/style.css     全部样式（配色取自川大官网主色 深红 #9a0000）
└─ images/           页面素材
   ├─ avatar.svg     占位头像（中性剪影）
   ├─ banner1~3.svg  轮播横幅
   └─ pic-*.svg      作品展示板块的插图
```

## 运行方式

直接用 Edge / Chrome 打开 `index.html` 即可，无需服务器、无需联网。

> 说明：仓库为公开项目，原始个人照片已替换为中性占位头像 `avatar.svg`，
> 联系方式均为 `example.com` 占位邮箱。
