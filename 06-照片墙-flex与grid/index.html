1-n-1 布局的照片墙

同一份页面内容、同一套照片卡片样式，分别用 Flex 与 Grid 两种布局技术实现： 顶部 1 个页头（header + nav），中间 n 张错落照片，底部 1 个页脚（footer）。

Flex 布局版

flex.html

display: flex + flex-wrap: wrap + flex: 1 1 var(--w)

打开预览 → Grid 布局版

grid.html

display: grid + repeat(auto-fill, minmax(220px, 1fr))

实验要求对照

  • 完整的 header、nav、body（main）、footer 页面元素；
  • 鼠标悬停在照片上时，照片产生旋转、形变的动画效果（@keyframes swing / transform / transition）；
  • 照片旋转后与相邻照片重叠，用 position: relative + z-index 把悬停照片抬到最上层；
  • 照片墙按 1-n-1 组织：1 张通栏开篇 + 10 张错落主体 + 1 张通栏收束。
